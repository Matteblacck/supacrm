# Как работает мини-CRM

В системе есть постановщики и исполнители. Постановщик добавляет стройки, создаёт задачи и назначает ответственного. Исполнитель видит только свои задачи и связанные с ними объекты. Он может начать работу и отправить результат на проверку.

Постановщик принимает результат или возвращает задачу на доработку с комментарием. Все изменения статуса сохраняются: видно, кто и когда выполнил действие, каким был прежний статус и что изменилось. Поэтому ход работы можно проверить по каждой задаче.

Права проверяет сама база данных — общее хранилище записей приложения. Даже если кто-то попробует обратиться к ней в обход кнопок и экранов, исполнитель не получит чужие задачи и не сможет сам принять свою работу. Новые учётные записи создаёт администратор, открытой регистрации нет. Удаление в интерфейсе скрывает запись из активной работы, а история остаётся сохранённой.
