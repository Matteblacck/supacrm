# Решения и допущения

- Физически записи не удаляются через приложение: задачи и объекты архивируются, чтобы сохранять авторство и историю изменений.
- Постановщик просматривает архив в отдельном разделе и может восстановить записи. Объект нельзя архивировать, пока у него есть активные задачи; сначала постановщик архивирует задачи. Для восстановления задачи её объект должен быть активным.
- Создание задачи записывается в историю как начальное событие «Создана · Новая».
- Возвращая задачу на доработку, постановщик обязан оставить комментарий.
- Новые пользователи автоматически получают роль исполнителя. Роль постановщика назначает администратор вручную в Supabase.
- Регистрация через приложение отсутствует; учетные записи создаются вручную в панели Supabase.
- Живой проект Supabase, тестовые учётные записи и опубликованный адрес приложения пока не созданы. Для этого нужен отдельный проект Supabase и аккаунт хостинга.
