# Мини-CRM «Объекты и задачи»

Веб-приложение для управления строительными объектами и задачами: постановщик назначает работу исполнителям, а команда отслеживает её выполнение.

## Возможности

- Управление объектами и задачами.
- Назначение исполнителей и контроль статусов.
- История изменений задач.
- Архивирование и восстановление объектов и задач.
- Разграничение доступа по ролям.

## Роли

- **Постановщик** — управляет объектами и задачами, назначает исполнителей и принимает работу.
- **Исполнитель** — видит назначенные ему активные задачи и обновляет их статус.

## Технологии

React, TypeScript, Vite и Supabase. Интерфейс разворачивается на Vercel; Supabase используется для авторизации и хранения данных с контролем доступа через RLS.
